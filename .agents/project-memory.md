# Memoria visual del proyecto

- Patrón de referencia para altas, ediciones y cargas en página propia: **Alta de establecimiento**.
- Usar ancho completo disponible, `AdminFormHeader`, `AdminFormCard`, controles `AdminFormField` con iconos, grilla y espaciados compartidos, fondo institucional y acciones separadas al pie.
- Los formularios equivalentes no deben introducir contenedores angostos, tarjetas anidadas, colores, tipografías, tamaños o barras de acciones diferentes.
- Antes de crear una pantalla nueva, buscar y reutilizar los componentes compartidos del patrón administrativo.
